# Noctralspy Login

Estudo de uma tela de login responsiva baseada em um layout criado no Figma. A interface inclui transições com Motion, estados completos do CTA de acesso e uma demonstração animada de produtos.

## Tecnologias

- React 19
- Vite 8
- Motion
- CSS

## Componentes

- `EmailField`: campo controlado de e-mail
- `AccessCodeButton`: estados desabilitado, ativo, carregando e sucesso
- `GoogleSignInButton`: ação de login social
- `LoginPanel`: composição e fluxo do formulário
- `StoreLink`: links das lojas
- `ProductWindow` e `ProductTable`: demonstração de busca, filtros e produtos
- `InsightsPanel`: composição do painel de insights

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
